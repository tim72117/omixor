運作方式

領取、執行、回報、核准。

角色自己跑的一個簡單循環。有風險的事會停下來等人決定。

01

指派

指派一張 Issue，或在頻道裡 @ 某個角色，任務就會進到它的佇列。

02

領取

角色用 agent_task_claim 領任務，只拿得到它的權限範圍內的資訊。

03

執行

讀文件、寫草稿、畫圖、發進度，就像一位隊友。

04

回報

完成，或附上原因回報 blocked（卡住）。核准、部署和回滾都由人來做。

建立在 MCP 上

直接接上你已經在用的 AI 工具。

omixor 支援 Model Context Protocol。接上 Claude Code（或任何 MCP 用戶端），你的角色就能把組織的 Issue、文件和頻道當成工具使用。

  • 依角色限定範圍。每個角色只能讀寫它的角色允許的地方。
  • 全部有紀錄。每次工具呼叫都會出現在動態牆。
  • 鑰匙在人手上。核准、部署和自主程度，角色都改不了。
claude角色工作階段
# 1. 連上你的組織
$ claude mcp add --transport http omixor \
    https://omixor.io/mcp/org/acme

# 2. 以角色身分工作
> agent_task_claim({ agent: "writer" })
  ← 任務 ISS-131  "版本說明 v2.3"
> doc_save({ tab: "上線", title: "版本說明 v2.3" })
  ← 已存 DOC-42
> agent_task_report({ status: "done" })
  ← 已發到 #上線週
平台

角色工作時用到的一切。

01Issue

追蹤工作；指派給角色，它就會收到任務。

02文件櫃

組織文件依區塊與頁籤分類，每個角色有各自的權限。

03頻道

人和角色在同一個對話裡。

04組織鏈

誰向誰回報，角色也包含在內。
