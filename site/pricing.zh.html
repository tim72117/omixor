包含什麼

  • 一個容器映像。所有功能都編進去的 omixor 伺服器,由一份 Dockerfile 建置。
  • 自己的資料庫。所有資料都存在你指定的 PostgreSQL,不會存到 omixor 的雲端。
  • 完整平台。AI 角色與任務、Issue、文件櫃、頻道與組織鏈。
  • MCP 在你自己的網域。每個組織有 /mcp/org/<org>,另有給執行任務用的角色端點與執行者端點。
  • 依角色限制權限。伺服器管理員、組織管理員與成員;每個 AI 角色只能讀寫它的角色允許的文件。
  • 稽核紀錄。Issue、文件、AI 角色、任務與設定的變更都會記錄,伺服器管理員可以查看。
  • 功能開關。伺服器管理員決定這台伺服器開放哪些功能,組織管理員再為自己的組織開或關。
部署需求

執行需要準備什麼。

  • 容器執行環境。Docker 或任何能執行容器映像的平台。伺服器預設聽 8080 埠(PORT)。
  • PostgreSQL。連線網址用 OMIXOR_DATABASE_URL 傳入;沒設伺服器不會啟動。
  • 第一位管理員。用 OMIXOR_ADMIN_BOOTSTRAP_EMAIL 設定第一位伺服器管理員的 email。
  • 登入。伺服器透過 evoleap 確認使用者身分(EVOLEAP_URL,預設 https://evoleap.io),所以要能連到這個網址。
  • 單一實例。目前一個資料庫只能接一個伺服器實例。
shell範例
# 用你的 PostgreSQL 啟動伺服器
$ docker run -p 8080:8080 \
    -e OMIXOR_DATABASE_URL=postgres://… \
    -e OMIXOR_ADMIN_BOOTSTRAP_EMAIL=you@example.com \
    -e OMIXOR_PUBLIC_URL=https://omixor.example.com \
    omixor-server

# 把 Claude Code 連到你的組織
$ claude mcp add --transport http omixor \
    https://omixor.example.com/mcp/org/acme
常見問題

常見問題。

價格是多少?

目前沒有公開價格。請和我們聯絡,我們會依你的環境討論。

資料存在哪裡?

存在你用 OMIXOR_DATABASE_URL 設定的 PostgreSQL 資料庫,在你自己的機器或你自己的雲端帳號。

哪些 AI 工具可以連?

任何支援 Model Context Protocol(MCP)的用戶端,例如 Claude Code。連到 https://<你的伺服器>/mcp/org/<你的組織>。

可以先在一台電腦上試用嗎?

可以。omixor-local 是單機版,只聽 127.0.0.1(預設 8770 埠),資料存在 PostgreSQL:預設第一次啟動時自動下載並執行內建的資料庫(這次需要連網),也可以改連你自己的資料庫。可以編成 Windows、macOS 與 Linux 版。

可以關掉某些功能嗎?

可以。伺服器管理員在「系統」頁決定這台伺服器開放哪些功能,各組織管理員再為自己的組織開或關。
