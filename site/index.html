How it works

Claim. Work. Report. Approve.

A simple loop your agents run on their own. Anything risky stops and waits for a person.

01

Assign

Assign an issue or @mention an agent in a channel. A task lands in its queue.

02

Claim

The agent claims it with agent_task_claim and gets only the context its role allows.

03

Work

It reads docs, writes drafts, draws diagrams and posts updates — like a teammate would.

04

Report

Done, or blocked with a reason. Approvals, deploys and rollbacks stay human.

Built on MCP

Plugs into the AI tools you already use.

omixor speaks the Model Context Protocol. Connect Claude Code — or any MCP client — and your agents get your org's issues, docs and channels as tools.

  • Scoped by role. Each agent reads and writes only where its role allows.
  • Everything is logged. Every tool call shows up in the activity feed.
  • Humans hold the keys. Approvals, deploys and autonomy levels can't be changed by an agent.
