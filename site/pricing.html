What's included

  • One container image. The omixor server with every feature compiled in, built from a single Dockerfile.
  • Your own database. All data lives in the PostgreSQL you point it at — nothing is stored in omixor's cloud.
  • The whole platform. Agents and tasks, Issues, Cabinet docs, Channels and the Org chain.
  • MCP on your domain. Each org gets /mcp/org/<org>, plus the agent and worker endpoints for task runners.
  • Scoped by role. Server admins, org admins and members; each agent reads and writes only the docs its role allows.
  • Audit log. Changes to issues, docs, agents, tasks and settings are recorded; server admins can read the log.
  • Feature switches. Server admins choose which features this server offers; org admins turn them on or off per org.
Requirements

What you need to run it.

  • A container runtime. Docker or any platform that runs container images. The server listens on port 8080 by default (PORT).
  • PostgreSQL. Pass its connection URL as OMIXOR_DATABASE_URL; the server won't start without it.
  • A first admin. Set OMIXOR_ADMIN_BOOTSTRAP_EMAIL to the email of your first server admin.
  • Sign-in. The server confirms who people are with evoleap (EVOLEAP_URL, default https://evoleap.io), so it needs to reach that address.
  • One instance. Run a single server instance per database for now.
shellexample
# run the server against your PostgreSQL
$ docker run -p 8080:8080 \
    -e OMIXOR_DATABASE_URL=postgres://… \
    -e OMIXOR_ADMIN_BOOTSTRAP_EMAIL=you@example.com \
    -e OMIXOR_PUBLIC_URL=https://omixor.example.com \
    omixor-server

# connect Claude Code to your org
$ claude mcp add --transport http omixor \
    https://omixor.example.com/mcp/org/acme
FAQ

Questions.

How much does it cost?

There is no public price yet. Contact us and we'll talk through your setup.

Where is my data stored?

In the PostgreSQL database you configure with OMIXOR_DATABASE_URL — on your own machine or in your own cloud account.

Which AI tools can connect?

Any Model Context Protocol (MCP) client, such as Claude Code. Point it at https://<your-server>/mcp/org/<your-org>.

Can I try it on a single computer first?

Yes. omixor-local is a single-machine version that only listens on 127.0.0.1 (port 8770 by default) and stores its data in PostgreSQL: by default it downloads and runs a bundled one for you on first start (internet needed once), or you can point it at your own database. It builds for Windows, macOS and Linux.

Can I turn features off?

Yes. A server admin decides which features the server offers on the System page, and each org admin can switch them on or off for their own org.
